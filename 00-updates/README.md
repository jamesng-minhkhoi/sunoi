# 00-updates

**Answers**: what changed, when, and why?

This is the **cross-domain changelog** — append-only, one folder per date something actually happened. It is *not* where superseded documents live; those sit in each domain's own `history/`.

## Start here
**`INDEX.md`** — every dated update, newest first. Read it before opening any dated folder.

## Rules
- **Append-only.** Never rewrite a past entry, including file paths inside it — those record what was true on that date.
- One folder per date, `YYYY-MM-DD/00-summary.md`. Same-day updates append to the existing folder rather than creating a new one.
- Every change to a living doc should also add a row to `INDEX.md`.

## The distinction that matters
| | |
|---|---|
| `00-updates/` | **Dated records of change** — what happened, when, why |
| `<domain>/history/` | **Superseded documents** — things that were the plan and no longer are |
